# Massonelec Sàrl — site web

Site statique (FR) de Massonelec Sàrl, installateur-électricien à Aigle.

- Sources : `_build/` (`build.py` génère toutes les pages dans `docs/`, `parts.py` = header, footer, formulaires, icônes).
- Publication : GitHub Pages depuis `docs/`.
- Régénérer : `python3 _build/build.py` · Aperçu local : `python3 _build/serve.py 4471`.
- Formulaires : sans serveur, ils ouvrent WhatsApp (079 350 55 19) ou la messagerie avec la demande pré-remplie.
